# 🆓 Бесплатные альтернативы MongoDB

## Проблема: MongoDB Atlas больше не показывает бесплатный M0

Если вы видите только платные тарифы ($0.09/час и выше), вот **бесплатные альтернативы**:

---

## Вариант 1: Railway (РЕКОМЕНДУЕТСЯ) ⭐

**Полностью бесплатно с кредитами!**

### Шаги:

1. **Откройте:** https://railway.app/
2. **Войдите через GitHub** (бесплатно)
3. **Создайте новый проект:**
   - Нажмите "New Project"
   - Выберите "Database" → "Add MongoDB"
4. **Railway создаст MongoDB автоматически**
5. **Получите строку подключения:**
   - Откройте созданную MongoDB
   - Перейдите в "Connect"
   - Скопируйте строку подключения (MONGODB_URL)

✅ **Бесплатно:** Railway дает $5 бесплатных кредитов каждый месяц (хватает на MongoDB)

---

## Вариант 2: Render

**Бесплатно с ограничениями**

### Шаги:

1. **Откройте:** https://render.com/
2. **Зарегистрируйтесь** (бесплатно)
3. **Создайте новый сервис:**
   - Нажмите "New" → "MongoDB"
   - Выберите бесплатный план (Free)
4. **Получите строку подключения:**
   - В настройках MongoDB скопируйте "Internal Database URL"

✅ **Бесплатно:** Render дает бесплатный MongoDB (с ограничениями по времени бездействия)

---

## Вариант 3: MongoDB Atlas через другой способ

### Попробуйте найти M0 через другой путь:

1. **В MongoDB Atlas попробуйте:**
   - Вверху страницы найдите "Try Free" или "Start Free"
   - Или перейдите в "Create" → "Cluster" → ищите "Free Tier"
   - Может быть скрыто в другом месте интерфейса

2. **Или используйте прямой URL:**
   - https://cloud.mongodb.com/ (вход)
   - После входа попробуйте найти "Free Tier" или "M0"

---

## Вариант 4: Supabase (PostgreSQL вместо MongoDB)

**Если MongoDB не обязателен, можно использовать PostgreSQL**

Supabase дает бесплатную базу данных PostgreSQL:
- https://supabase.com/
- Полностью бесплатно
- Но нужно будет изменить код под PostgreSQL (не MongoDB)

---

## Вариант 5: Local MongoDB (только для разработки)

**Если нужен только для локальной разработки:**

Можно установить MongoDB локально на компьютер:
- Скачать: https://www.mongodb.com/try/download/community
- Установить
- Использовать `mongodb://localhost:27017/site`

⚠️ **Работает только на вашем компьютере, не в интернете!**

---

## ⭐ РЕКОМЕНДАЦИЯ: Используйте Railway

**Почему Railway:**
- ✅ Проще всего настроить
- ✅ Бесплатно ($5 кредитов/месяц хватает)
- ✅ Автоматически выдает строку подключения
- ✅ Работает как MongoDB Atlas

### Пошаговая инструкция для Railway:

1. **Откройте:** https://railway.app/
2. **Войдите через GitHub**
3. **"New Project" → "Database" → "Add MongoDB"**
4. **Скопируйте строку подключения** (MONGODB_URL)
5. **Используйте в Vercel** как MONGODB_URI

---

## Как использовать строку подключения

После того как получите строку подключения из Railway/Render:

1. **В Vercel:**
   - Settings → Environment Variables
   - Добавьте: `MONGODB_URI` = ваша строка подключения

2. **Строка подключения обычно выглядит так:**
   ```
   mongodb://mongo:27017/dbname
   ```
   или
   ```
   mongodb+srv://user:pass@cluster.mongodb.net/dbname
   ```

## Что выбрать?

**Для вашего проекта рекомендую:**

1. **Railway** - самый простой и бесплатный вариант
2. **Render** - если Railway не подходит
3. **MongoDB Atlas** - только если найдете бесплатный M0

- ✅ Код остается таким же
- ✅ Только меняется строка подключения (MONGODB_URI)
- ✅ Все остальное работает без изменений
