# Пошаговая инструкция: От локального проекта до работающего сайта в интернете

## 🎯 Цель: Загрузить ваш сайт в интернет

---

## ✅ ШАГ 1: Подготовка (5 минут)

### 1.1. Установите Git (если еще не установлен)
- Скачайте: https://git-scm.com/download/win
- Установите с настройками по умолчанию
- Откройте PowerShell

### 1.2. Проверьте установку:
```bash
git --version
```
Должна показаться версия Git.

---

## ✅ ШАГ 2: Создайте аккаунт на GitHub (3 минуты)

1. Перейдите на https://github.com/signup
2. Зарегистрируйтесь (можно через email или Google)
3. Подтвердите email адрес

---

## ✅ ШАГ 3: Создайте репозиторий на GitHub (2 минуты)

1. На GitHub нажмите **"+"** (правый верхний угол) → **"New repository"**
2. Заполните:
   - **Repository name**: `site-applications` (или любое другое название)
   - Выберите **Private** (если не хотите, чтобы код был публичным)
   - ❌ **НЕ ставьте галочки** на README, .gitignore, license
3. Нажмите **"Create repository"**

---

## ✅ ШАГ 4: Создайте Personal Access Token для GitHub (5 минут)

1. На GitHub: ваш аватар → **Settings**
2. Левое меню: **Developer settings**
3. **Personal access tokens** → **Tokens (classic)**
4. **"Generate new token"** → **"Generate new token (classic)"**
5. Заполните:
   - **Note**: `Мой компьютер`
   - **Expiration**: `No expiration` (или выберите срок)
   - ✅ Отметьте **`repo`** (полный доступ)
6. Нажмите **"Generate token"**
7. **СКОПИРУЙТЕ ТОКЕН** (показывается только один раз!)

---

## ✅ ШАГ 5: Загрузите файлы в GitHub (5 минут)

Откройте PowerShell в папке вашего проекта:

```bash
# Перейдите в папку проекта
cd C:\Users\Admin\Desktop\site

# Инициализируйте Git
git init

# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Initial commit"

# Подключите GitHub (ЗАМЕНИТЕ YOUR_USERNAME и YOUR_REPO на ваши!)
# Пример: git remote add origin https://github.com/ivanov/site-applications.git
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Переименуйте ветку
git branch -M main

# Загрузите файлы
git push -u origin main
```

**При запросе логина/пароля:**
- Username: ваш GitHub username
- Password: вставьте скопированный токен из Шага 4

**Проверьте:** Зайдите на https://github.com/YOUR_USERNAME/YOUR_REPO - должны увидеть все файлы!

## ✅ ШАГ 6: Настройте MongoDB Atlas (10 минут)

### 6.1. Регистрация
1. Перейдите на https://www.mongodb.com/cloud/atlas/register
2. Зарегистрируйтесь (можно через Google)

### 6.2. Создайте кластер
1. После регистрации выберите **"Build a Database"**
2. Выберите план **FREE (M0)** - бесплатный
3. Выберите провайдера (AWS, Google Cloud или Azure)
4. Выберите регион (ближайший к вам)
5. Название кластера: оставьте по умолчанию или любое
6. Нажмите **"Create"**

### 6.3. Настройте доступ
1. **Database Access** (безопасность → доступ к базе):
   - Нажмите **"Add New Database User"**
   - Username: `admin` (или любое)
   - Password: создайте и **ЗАПОМНИТЕ** пароль
   - Database User Privileges: **"Atlas admin"**
   - Нажмите **"Add User"**

2. **Network Access** (безопасность → сетевой доступ):
   - Нажмите **"Add IP Address"**
   - Выберите **"Allow Access from Anywhere"** (0.0.0.0/0)
   - Нажмите **"Confirm"**

### 6.4. Получите строку подключения
1. Нажмите **"Connect"** на вашем кластере
2. Выберите **"Connect your application"**
3. Скопируйте строку подключения (выглядит так):
   ```
   mongodb+srv://admin:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```
4. **Замените `<password>`** на ваш пароль пользователя
5. **Добавьте название базы** в конце: `/site?retryWrites=true&w=majority`
   - Итоговая строка будет:
   ```
   mongodb+srv://admin:ВАШ_ПАРОЛЬ@cluster0.xxxxx.mongodb.net/site?retryWrites=true&w=majority
   ```
6. **СОХРАНИТЕ ЭТУ СТРОКУ** - она понадобится в следующем шаге!

## ✅ ШАГ 7: Разверните сайт на Vercel (10 минут)

### 7.1. Регистрация
1. Перейдите на https://vercel.com/signup
2. Войдите через **GitHub** (рекомендуется - проще подключить репозиторий)

### 7.2. Подключите проект
1. После входа нажмите **"Add New..."** → **"Project"**
2. Найдите ваш репозиторий в списке (из GitHub)
3. Нажмите **"Import"** рядом с ним

### 7.3. Настройте переменные окружения
1. В разделе **"Environment Variables"** добавьте:

   **Переменная 1:**
   - Name: `MONGODB_URI`
   - Value: вставьте строку подключения из Шага 6.4
   - Environment: выберите все (Production, Preview, Development)
   - Нажмите **"Add"**

   **Переменная 2:**
   - Name: `JWT_SECRET`
   - Value: сгенерируйте случайный ключ:
     - Перейдите на https://randomkeygen.com/
     - Скопируйте любой "CodeIgniter Encryption Keys" (длинная строка)
     - Или сгенерируйте свою: `openssl rand -base64 32` (в PowerShell)
   - Environment: выберите все
   - Нажмите **"Add"**

2. Нажмите **"Deploy"** внизу страницы

### 7.4. Дождитесь деплоя
- Vercel начнет сборку проекта (займет 2-5 минут)
- После завершения вы увидите ссылку вида: `your-project.vercel.app`
- **СОХРАНИТЕ ЭТУ ССЫЛКУ!**

## ✅ ШАГ 8: Создайте первого администратора (5 минут)

### Вариант А: Через скрипт (рекомендуется)

Откройте PowerShell в папке проекта:

```bash
cd C:\Users\Admin\Desktop\site

# Замените YOUR_MONGODB_URI на вашу строку из Шага 6.4
# Замените email, password, name на свои значения
$env:MONGODB_URI="mongodb+srv://admin:ПАРОЛЬ@cluster0.xxxxx.mongodb.net/site?retryWrites=true&w=majority"
npm run init-admin admin@example.com password123 "Руководитель отдела"
```

### Вариант Б: Через MongoDB Atlas

1. В MongoDB Atlas нажмите **"Browse Collections"**
2. Если база пустая, создайте базу данных `site` и коллекцию `users`
3. Нажмите **"Insert Document"**
4. Вставьте (замените email и захешированный пароль):
   ```json
   {
     "email": "admin@example.com",
     "password": "ЗАХЕШИРОВАННЫЙ_ПАРОЛЬ",
     "name": "Руководитель отдела",
     "role": "superadmin",
     "createdAt": new Date(),
     "updatedAt": new Date()
   }
   ```
5. Для хеширования пароля используйте: https://bcrypt-generator.com/ (rounds: 10)

## ✅ ШАГ 9: Проверьте работу сайта (2 минуты)

1. Откройте ссылку от Vercel (из Шага 7.4)
2. Должна открыться страница входа
3. Войдите с данными администратора (из Шага 8)
4. Проверьте, что все работает!

## ✅ ШАГ 10: Подключите свой домен (опционально, 15 минут)

### 10.1. Купите домен
- Например, на https://unihost.kz/
- Выберите домен (например, `vash-sait.kz`)
- Оформите покупку

### 10.2. Настройте в Vercel
1. В Vercel: ваш проект → **Settings** → **Domains**
2. Нажмите **"Add Domain"**
3. Введите ваш домен (например, `vash-sait.kz`)
4. Vercel покажет инструкции по настройке DNS

### 10.3. Настройте DNS у регистратора (Unihost.kz)
1. Войдите в личный кабинет Unihost.kz
2. Найдите ваш домен → **"Управление доменом"**
3. Найдите **"DNS серверы"** или **"Name Servers"**
4. Замените на NS записи от Vercel (Vercel покажет, какие именно)
5. Сохраните изменения

### 10.4. Дождитесь применения (1-2 часа)
- Через 1-2 часа сайт будет доступен по вашему домену
- HTTPS настроится автоматически

## ❓ Если что-то пошло не так

### Ошибка при загрузке в GitHub:
- Проверьте, что используете Personal Access Token, а не пароль
- Убедитесь, что токен имеет права `repo`

### Ошибка подключения к MongoDB:
- Проверьте, что добавили IP 0.0.0.0/0 в Network Access
- Убедитесь, что заменили `<password>` в строке подключения

### Сайт не работает после деплоя:
- Проверьте логи в Vercel (Deployments → ваш деплой → View Function Logs)
- Убедитесь, что переменные окружения установлены правильно

### Не могу войти:
- Убедитесь, что создали первого администратора (Шаг 8)
- Проверьте правильность email и пароля
