# 👤 Создание первого администратора

## Способ 1: Через код (РЕКОМЕНДУЕТСЯ)

### Вариант А: Использовать существующий скрипт

1. **В Railway создайте временный сервис:**
   - Откройте Railway → ваш проект
   - Нажмите "New" → "Empty Service"
   - Назовите например "create-admin"

2. **Или используйте локально:**
   - Откройте терминал в папке проекта
   - Установите переменную окружения с `MONGODB_URI` из Railway
   - Запустите скрипт

Но это сложно. Лучше использовать Способ 2.

---

## Способ 2: Через API сайта (САМЫЙ ПРОСТОЙ) ⭐

### Вариант А: Временно добавить код создания администратора

Можно временно добавить код в ваш сайт, который создаст администратора при первом запуске.

---

## Способ 3: Через MongoDB Atlas (если есть)

Если у вас есть доступ к MongoDB Atlas (которую мы настраивали раньше):
- Используйте MongoDB Compass с строкой подключения из Atlas
- Создайте пользователя там

---

## Способ 4: Через Railway Web UI (если доступно)

1. **В Railway откройте MongoDB**
2. **Перейдите в "Data" или "Database"**
3. **Найдите возможность добавить документ напрямую**
4. **Создайте коллекцию `users` и добавьте документ**

---

## Рекомендация: Использовать временный API endpoint

Создам для вас временный API endpoint, который создаст администратора.
