# Инструкция по развертыванию сайта в интернете

## Вариант 1: Vercel + MongoDB Atlas (Рекомендуется - самый простой)

### Шаг 1: Настройка MongoDB Atlas (Бесплатная облачная база данных)

1. **Зарегистрируйтесь на MongoDB Atlas:**
   - Перейдите на https://www.mongodb.com/cloud/atlas/register
   - Создайте бесплатный аккаунт

2. **Создайте кластер:**
   - После регистрации создайте бесплатный кластер (M0)
   - Выберите провайдера (AWS, Google Cloud или Azure)
   - Выберите регион ближайший к вам
   - Нажмите "Create Cluster"

3. **Настройте доступ:**
   - В разделе "Security" → "Database Access" создайте пользователя базы данных
   - Запомните логин и пароль
   - В разделе "Security" → "Network Access" добавьте IP адрес `0.0.0.0/0` (разрешить доступ откуда угодно)

4. **Получите строку подключения:**
   - Нажмите "Connect" на вашем кластере
   - Выберите "Connect your application"
   - Скопируйте строку подключения (она выглядит как `mongodb+srv://username:password@cluster.mongodb.net/dbname`)
   - Замените `<password>` на ваш пароль пользователя
   - Замените `<dbname>` на название базы (например, `site`)

### Шаг 2: Подготовка проекта для GitHub

1. **Создайте аккаунт на GitHub** (если еще нет): https://github.com/signup

2. **Создайте новый репозиторий:**
   - Нажмите "New repository"
   - Назовите репозиторий (например, `site-applications`)
   - Сделайте его публичным или приватным (как хотите)
   - НЕ добавляйте README, .gitignore или лицензию (они уже есть)

3. **Загрузите код в GitHub:**
   ```bash
   # Инициализируйте git (если еще не сделано)
   git init
   
   # Добавьте все файлы
   git add .
   
   # Создайте первый коммит
   git commit -m "Initial commit"
   
   # Добавьте удаленный репозиторий (замените YOUR_USERNAME и YOUR_REPO на ваши)
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   
   # Загрузите код
   git branch -M main
   git push -u origin main
   ```

### Шаг 3: Развертывание на Vercel

1. **Зарегистрируйтесь на Vercel:**
   - Перейдите на https://vercel.com/signup
   - Войдите через GitHub (рекомендуется)

2. **Подключите проект:**
   - Нажмите "Add New..." → "Project"
   - Выберите ваш репозиторий из GitHub
   - Нажмите "Import"

3. **Настройте переменные окружения:**
   - В разделе "Environment Variables" добавьте:
     - `MONGODB_URI` = ваша строка подключения из MongoDB Atlas
     - `JWT_SECRET` = любой случайный секретный ключ (например, сгенерируйте на https://randomkeygen.com/)
   - Нажмите "Deploy"

4. **Дождитесь деплоя:**
   - Vercel автоматически соберет и задеплоит ваш сайт
   - После завершения вы получите ссылку вида `your-project.vercel.app`

### Шаг 4: Создание первого администратора

После деплоя нужно создать первого "Руководителя отдела":

1. **Подключитесь к MongoDB Atlas:**
   - Зайдите в MongoDB Atlas → "Browse Collections"
   - Если база пустая, создайте коллекцию `users`

2. **Создайте пользователя через MongoDB Compass или Atlas UI:**
   - Используйте MongoDB Compass (https://www.mongodb.com/products/compass) или веб-интерфейс Atlas
   - Создайте документ в коллекции `users`:
   ```json
   {
     "email": "admin@example.com",
     "password": "хешированный_пароль",
     "name": "Администратор",
     "role": "superadmin"
   }
   ```
   
   **Важно:** Пароль должен быть захеширован с помощью bcrypt. Вы можете:
   - Запустить локально скрипт `npm run init-admin` с правильным `MONGODB_URI`
   - Или использовать онлайн bcrypt генератор: https://bcrypt-generator.com/ (rounds: 10)

3. **Альтернативный способ - через API:**
   - Можно временно изменить код, чтобы создать первого пользователя через API

## Вариант 2: Railway (Хостинг + База данных в одном месте)

### Шаг 1: Регистрация
- Перейдите на https://railway.app/
- Войдите через GitHub

### Шаг 2: Создание проекта
- Нажмите "New Project"
- Выберите "Deploy from GitHub repo"
- Выберите ваш репозиторий

### Шаг 3: Добавление MongoDB
- В проекте нажмите "New" → "Database" → "Add MongoDB"
- Railway автоматически создаст базу данных

### Шаг 4: Настройка переменных окружения
- В настройках проекта добавьте:
  - `MONGODB_URI` - скопируйте из созданной MongoDB базы
  - `JWT_SECRET` - сгенерируйте случайный ключ

### Шаг 5: Деплой
- Railway автоматически задеплоит проект
- Вы получите ссылку вида `your-project.up.railway.app`

## Подключение своего домена

### Где купить домен?

Популярные регистраторы доменов:
- **Unihost.kz** (https://unihost.kz/) - ⭐ **Рекомендуется для Казахстана**, домены .kz, .com.kz, хостинг, VPS, поддержка 24/7
- **REGISTRATOR.KZ** (https://www.registrator.kz/) - для доменов .kz
- **Namecheap** (https://www.namecheap.com/) - от $8-15/год, международный
- **GoDaddy** (https://www.godaddy.com/) - от $10-20/год, международный
- **Reg.ru** (https://www.reg.ru/) - для доменов .ru, .рф
- **Timeweb** (https://timeweb.com/) - российский регистратор

### Подключение домена к Vercel

1. **Купите домен** у любого регистратора

2. **В панели Vercel:**
   - Откройте ваш проект
   - Перейдите в "Settings" → "Domains"
   - Нажмите "Add Domain"
   - Введите ваш домен (например, `vash-sait.kz`)
   - Vercel покажет инструкции по настройке DNS

3. **Настройте DNS записи** у вашего регистратора:
   
   **Вариант А: Использовать DNS Vercel (рекомендуется)**
   - Vercel предоставит NS (Name Server) записи
   - В панели регистратора домена замените NS записи на те, что дал Vercel
   - Пример NS записей от Vercel:
     ```
     ns1.vercel-dns.com
     ns2.vercel-dns.com
     ```
   
   **Вариант Б: Добавить A/CNAME записи (если не хотите менять NS)**
   - В DNS настройках регистратора добавьте:
     - Для основного домена (`vash-sait.kz`): 
       - Тип: `A` 
       - Значение: IP адрес от Vercel (Vercel покажет его)
     - Или тип: `CNAME` 
       - Значение: `cname.vercel-dns.com`
     - Для поддомена `www.vash-sait.kz`:
       - Тип: `CNAME`
       - Значение: `cname.vercel-dns.com`

4. **Дождитесь распространения DNS** (обычно 5-60 минут, может быть до 24 часов)

5. **Проверьте SSL сертификат:**
   - Vercel автоматически выпустит бесплатный SSL сертификат (HTTPS)
   - Через несколько минут сайт будет доступен по `https://vash-sait.kz`

### Подключение домена к Railway

1. В проекте Railway перейдите в "Settings" → "Domains"
2. Нажмите "Generate Domain"
3. Railway создаст поддомен типа `your-project.up.railway.app`
4. Для своего домена:
   - Добавьте CNAME запись у регистратора:
     - Имя: `@` или `www`
     - Значение: `your-project.up.railway.app`
   - Railway автоматически настроит SSL

### Пример настройки DNS для домена .kz

#### Если покупаете домен через Unihost.kz:

1. **Войдите в личный кабинет** Unihost.kz (https://unihost.kz/)

2. **Перейдите в управление доменом:**
   - Найдите ваш домен в списке
   - Нажмите на домен или перейдите в "Управление доменом"

3. **Настройте DNS записи:**
   
   **Вариант 1: Использовать DNS Vercel (рекомендуется)**
   - Найдите раздел "DNS серверы" или "Name Servers"
   - Замените текущие NS записи на те, что предоставил Vercel:
     ```
     ns1.vercel-dns.com
     ns2.vercel-dns.com
     ```
   - Сохраните изменения
   
   **Вариант 2: Добавить A/CNAME записи**
   - Найдите раздел "DNS записи" или "Управление DNS"
   - Добавьте записи:
     ```
     Тип: A
     Имя: @ (или оставьте пустым для основного домена)
     Значение: IP адрес от Vercel (Vercel покажет в настройках домена)
     TTL: 3600
     
     Тип: CNAME
     Имя: www
     Значение: cname.vercel-dns.com
     TTL: 3600
     ```
   - Сохраните изменения

4. **Дождитесь применения изменений** (обычно 1-2 часа)

#### Если покупаете домен через REGISTRATOR.KZ:

1. Войдите в панель управления доменом
2. Перейдите в "DNS записи" или "Управление DNS"
3. Добавьте записи:
   ```
   Тип: A
   Имя: @
   Значение: IP от Vercel (Vercel покажет)
   TTL: 3600
   
   Тип: CNAME
   Имя: www
   Значение: cname.vercel-dns.com
   TTL: 3600
   ```
4. Сохраните изменения

### Важные замечания

- ⏱️ **DNS изменения могут занять до 24 часов**, но обычно работают за 1-2 часа
- 🔒 **SSL сертификат** выдается автоматически и бесплатно (HTTPS)
- 🌍 **WWW и без WWW**: Vercel автоматически настроит оба варианта (`site.kz` и `www.site.kz`)
- 💰 **Стоимость**: Покупка домена обычно стоит $8-20 в год, Vercel бесплатен
- ✅ **Рекомендация**: Используйте DNS Vercel (вариант А) - это проще и надежнее

## Важные замечания

- ⚠️ **JWT_SECRET**: Обязательно измените на сложный случайный ключ в продакшене
- ⚠️ **MONGODB_URI**: Никогда не публикуйте в открытом доступе
- ✅ Все переменные окружения настраиваются в панели хостинга, НЕ в коде
- ✅ После деплоя автоматически создаются новые версии при каждом push в GitHub
