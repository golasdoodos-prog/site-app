# 🗄️ Настройка MongoDB Atlas (Бесплатный кластер)

## Шаг 1: Регистрация

1. **Откройте:** https://www.mongodb.com/cloud/atlas/register
2. **Заполните форму:**
   - Введите ваш email
   - Придумайте пароль
   - Или войдите через Google/GitHub (проще)
3. **Нажмите "Sign Up"**

---

## Шаг 2: Создание бесплатного кластера

1. **После регистрации вы увидите страницу "Deploy a cloud database"**
2. **Выберите вариант "M0" (FREE)** - это бесплатный тариф
3. **Выберите провайдера:**
   - AWS (рекомендуется)
   - Google Cloud
   - Azure
   - Любой из них - разницы нет для бесплатного тарифа

4. **Выберите регион:**
   - Выберите ближайший к Казахстану (например: `Asia Pacific`)
   - Можно выбрать `Mumbai` или `Singapore` (ближе всего)

5. **Название кластера:**
   - Можно оставить по умолчанию (например: `Cluster0`)
   - Или назвать по-своему

6. **Нажмите "Create Deployment"** (внизу страницы)

⏱️ **Подождите 3-5 минут** пока создается кластер

---

## Шаг 3: Настройка доступа к базе данных

### 3.1. Создание пользователя базы данных

1. **Вы увидите окно "Create Database User"**
2. **Выберите способ аутентификации:**
   - Оставьте "Password" (по умолчанию)

3. **Введите данные пользователя:**
   - **Username:** например, `admin` или `myuser`
   - **Password:** придумайте надежный пароль
   - **⚠️ ВАЖНО: Запомните или сохраните пароль!**

4. **Нажмите "Create Database User"**

### 3.2. Настройка сетевого доступа

1. **Вы увидите окно "Where would you like to connect from?"**
2. **Выберите "My Local Environment"** (для начала)
3. **Или нажмите "Add My Current IP Address"** (добавит ваш IP)

**Но лучше разрешить доступ откуда угодно:**

1. **Нажмите "Cancel"** или закройте окно
2. **Перейдите в раздел "Network Access"** (слева в меню)
3. **Нажмите "Add IP Address"**
4. **Нажмите "Allow Access from Anywhere"** (добавит `0.0.0.0/0`)
5. **Нажмите "Confirm"**

✅ Теперь ваша база доступна из любого места (нужно для Vercel)

---

## Шаг 4: Получение строки подключения

1. **На главной странице нажмите "Connect"** на вашем кластере

2. **Выберите "Connect your application"**

3. **Выберите версию драйвера:**
   - Выберите "Node.js" (если не выбрано)
   - Версию можно оставить любую (обычно показывается последняя)

4. **Скопируйте строку подключения:**
   ```
   mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```

5. **Замените в строке:**
   - `<username>` → ваш username (который создали в шаге 3.1)
   - `<password>` → ваш password (который создали в шаге 3.1)
   - После `.net/` добавьте название базы: `site` 
   
   **Итоговая строка должна выглядеть так:**
   ```
   mongodb+srv://admin:mypassword123@cluster0.xxxxx.mongodb.net/site?retryWrites=true&w=majority
   ```

✅ **Сохраните эту строку - она понадобится для Vercel!**

---

## Шаг 5: Проверка подключения (опционально)

1. **В MongoDB Atlas нажмите "Browse Collections"** (слева в меню)
2. **Если база пустая - это нормально**
3. **После деплоя вашего приложения здесь появятся коллекции**

---

## ✅ Готово!

Теперь у вас есть:
- ✅ Бесплатный кластер MongoDB
- ✅ Пользователь базы данных
- ✅ Строка подключения

## 📝 Что дальше?

Используйте строку подключения в:
- **Vercel:** Environment Variables → `MONGODB_URI`
- **Или локально:** в файле `.env.local`

## 💡 Важные моменты

- ✅ **Бесплатный тариф M0:**
  - 512 MB хранилища
  - Достаточно для небольших проектов
  - Бесплатно навсегда

- ⚠️ **Запомните пароль пользователя!** Если забудете - нужно будет создать нового пользователя

- 🔒 **Строка подключения содержит пароль** - не публикуйте ее в открытом доступе!

- 📊 **Мониторинг:**
  - В MongoDB Atlas можно смотреть статистику использования
  - Лимиты бесплатного тарифа: 512 MB хранилища

---

## 🆘 Если что-то не работает

1. **Не могу создать кластер:**
   - Убедитесь, что выбрали вариант "M0" (FREE)
   - Проверьте, что регистрация завершена

2. **Не могу подключиться:**
   - Проверьте, что добавили IP `0.0.0.0/0` в Network Access
   - Проверьте, что правильно заменили `<username>` и `<password>` в строке подключения

3. **Забыл пароль:**
   - Database Access → выберите пользователя → "Edit" → измените пароль
   - Или создайте нового пользователя
