# ✅ Как проверить что всё работает

## 1. Проверка деплоя в Vercel

### Шаг 1: Проверьте статус деплоя
1. Откройте Vercel: https://vercel.com
2. Откройте ваш проект
3. Перейдите в "Deployments"
4. Проверьте статус последнего деплоя:
   - ✅ **"Ready"** (зеленый) = всё хорошо
   - ❌ **"Error"** (красный) = есть ошибка, смотрите логи

### Шаг 2: Проверьте логи (если есть ошибки)
1. Нажмите на деплой (если он красный)
2. Откройте вкладку "Logs"
3. Посмотрите ошибки:
   - Если видите "MONGODB_URI is not defined" → переменная не добавлена
   - Если видите ошибку подключения к MongoDB → проверьте строку подключения

### Шаг 3: Откройте сайт
1. В Vercel нажмите на ссылку вашего проекта (например: `ваш-проект.vercel.app`)
2. Или нажмите "Visit" рядом с деплоем
3. Сайт должен открыться

---

## 2. Проверка подключения к MongoDB

### Способ А: Через сайт (проще)

1. **Откройте ваш сайт** (ссылка из Vercel)
2. **Попробуйте зарегистрироваться или войти:**
   - Если сайт открывается = MongoDB подключена
   - Если видите ошибку "Database connection failed" = проблема с подключением

3. **Проверьте в MongoDB (Railway):**
   - Откройте Railway → ваша MongoDB
   - Перейдите в "Database" или "Data"
   - Если видите коллекции `users`, `applications` = всё работает!

### Способ Б: Через MongoDB Compass (детальная проверка)

1. **Скачайте MongoDB Compass:**
   - https://www.mongodb.com/products/compass

2. **Подключитесь:**
   - В Railway скопируйте `MONGO_URL`
   - Откройте MongoDB Compass
   - Вставьте строку подключения
   - Нажмите "Connect"

3. **Проверьте базу:**
   - Должна быть база данных (например: `railway` или `site`)
   - Внутри должны быть коллекции: `users`, `applications`

---

## 3. Проверка переменных окружения

### В Vercel:
1. Settings → Environment Variables
2. Проверьте что есть:
   - ✅ `MONGODB_URI` (со значением)
   - ✅ `JWT_SECRET` (со значением)

### Если переменных нет:
1. Добавьте их (см. предыдущие инструкции)
2. Нажмите "Redeploy" на последнем деплое
3. Или в меню деплоя → "Redeploy"

---

## 4. Проверка работы функций сайта

### Проверьте основные функции:

1. **Откройте сайт:** `https://ваш-проект.vercel.app`

2. **Проверьте страницу входа:**
   - Должна открываться без ошибок
   - URL: `/login`

3. **Создайте первого администратора:**
   - Через MongoDB Compass создайте пользователя в коллекции `users`:
   ```json
   {
     "email": "admin@example.com",
     "password": "$2a$10$хешированный_пароль",
     "name": "Администратор",
     "role": "superadmin"
   }
   ```
   - Используйте https://bcrypt-generator.com/ для хеша пароля

4. **Войдите на сайт:**
   - Используйте созданные данные
   - Должна открыться панель администратора

5. **Проверьте создание заявки:**
   - Создайте тестовую заявку
   - Проверьте что она сохранилась в MongoDB

---

## 5. Проверка через консоль браузера

1. **Откройте сайт**
2. **Нажмите F12** (откроется DevTools)
3. **Перейдите в "Console"**
4. **Проверьте ошибки:**
   - ✅ Нет красных ошибок = всё хорошо
   - ❌ Есть ошибки = смотрите что написано

5. **Перейдите в "Network":**
   - Обновите страницу (F5)
   - Проверьте запросы к API:
     - `/api/auth/login` - должен быть 200 (успех) или 401 (неавторизован)
     - `/api/applications` - должен быть 200 или 401

## 🆘 Если что-то не работает

### Проблема: Сайт не открывается
- Проверьте логи в Vercel → Deployments → Logs
- Убедитесь что деплой завершился успешно

### Проблема: Ошибка подключения к MongoDB
- Проверьте переменную `MONGODB_URI` в Vercel
- Убедитесь что скопировали правильное значение из Railway
- Проверьте что MongoDB в Railway запущена (зеленый статус)

### Проблема: "JWT_SECRET is not defined"
- Добавьте переменную `JWT_SECRET` в Vercel
- Сделайте Redeploy

### Проблема: Не могу войти
- Убедитесь что создали пользователя в MongoDB
- Проверьте что пароль захеширован правильно (bcrypt)
- Проверьте роль пользователя: `"role": "superadmin"`

---
